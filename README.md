## Projects-Using-aisstream.io

This repo is for tracking projects which use aisstream.io. In the future we will begin linking to these projects from the aisstream.io website. 

### How do I add my project ? 

1. Open a issue with the following information

```
Name Of Project: AI GPS jamming detection system for veasels
Link To Project Github or Website: <no project yet>
Brief Description or Elevator Pitch: In today’s increasingly contested maritime environments, vessels face growing threats from GPS jamming and spoofing, which can disrupt navigation, logistics, and safety. Our AI-powered GPS jamming detection system monitors ADS-B, AIS, and onboard sensor data in real time to identify and classify anomalies in GNSS signals. Using machine learning, it alerts crews and command centers to potential interference — enabling faster response, safer routing, and operational continuity. Lightweight, scalable, and hardware-agnostic, our solution adds a critical layer of intelligence to maritime situational awareness
Assets: Link to any relevent image assets: working on it
```
